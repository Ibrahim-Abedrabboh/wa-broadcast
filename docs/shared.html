المحرك الأساسي

WA Broadcast

منصة رسائل واتساب متعددة المستأجرين ومستضافة ذاتياً على Meta Cloud API. المحرك القوي خلف كل شيء.

  • تعدد عملاء كامل (كل عميل له رقمه)
  • صندوق وارد ثنائي الاتجاه
  • قوالب غنية (وسائط، كوبونات، شرائط)
  • جدولة حملات متكررة
  • تحليلات مفصلة وقمع تسليم
  • Node.js + PostgreSQL + Redis
GitHub → المزيد
الواجهة المحسّنة

WhatsApp Hub

واجهة مستخدم محسّنة مبنية على كود WA Broadcast. تجربة مستخدم أفضل مع نفس القوة تحت الغطاء.

  • لوحة تحكم تحليلية متقدمة
  • تصميم عصري داكن (Teal/Green)
  • دعم RTL كامل للعربية
  • نظام تصميم موحد
  • صفحة هبوط ثنائية اللغة
  • Next.js 15 + TypeScript
